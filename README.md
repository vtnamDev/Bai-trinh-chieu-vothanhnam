# BioSphere Slides

A Vietnamese, mobile-first presentation workspace prototype for school science presentations.

## Current prototype
- Library for presentation drafts and templates
- Click/tap the right side to advance; left side to go back
- Fullscreen presentation mode on supported desktop browsers
- Arrow-key navigation, progress indicator, responsive layout
- Local draft storage and JSON import/export

## Important limitations
This is a frontend prototype. Drafts stored in localStorage are only available in the same browser/device. Secure password protection, accounts, server-side storage, and teacher-facing share links require a backend and are not implemented yet.

The KHTN 8, Volume 1, Lesson 32 sections V–VI presentation is intentionally a content scaffold until the textbook and teacher's assignment are provided and verified.
